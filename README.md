### 🔬 Research & Recent Work
- 📄 **Latest Paper / Research Project:** **Smart-GaitBox: A Universal IoT Device for FoG Mitigation and Remote Health Monitoring in Parkinson’s Disease** — Designed and engineered a universal retrofittable IoT smart module utilizing an embedded controller, an inertial measurement unit (IMU), and a pulse sensor for real-time mobility monitoring, Freezing of Gait (FoG) mitigation, and cloud data logging.
- 🔭 **Previous Key Work:** AI-Driven Self-Organizing Networks (SON) Coverage Optimization framework focused on antenna-tilt adaptation and automated network enhancements.
- 🌱 **Exploring:** Advanced MLOps pipelines, scalable cloud deployment architectures, and real-time deep learning edge execution workflows.
